# 폰케어 개인정보처리방침

시행일: 2026년 10월 25일

폰케어(이하 "앱")는 휴대폰의 저장공간·배터리·성능 상태를 점검하고 정리하는 앱입니다. 앱은 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리합니다.

## 1. 수집하는 정보

**앱은 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.**

앱이 기능을 제공하려고 휴대폰 안에서만 읽는 정보는 다음과 같습니다. 이 정보는 휴대폰 밖으로 나가지 않습니다.

| 읽는 정보 | 쓰는 곳 | 필요한 권한 |
|---|---|---|
| 파일 이름·크기·날짜, 사진·동영상 | 정리 후보, 중복 사진, 메신저 파일, 동영상 압축 | 모든 파일 접근 |
| 앱별 사용 시간·마지막 사용일·데이터 사용량 | 안 쓰는 앱, 많이 쓴 앱, 데이터 사용량 | 사용 기록 접근 |
| 알림을 보낸 앱 이름과 개수 (알림 제목·내용은 읽지 않음) | 알림 많은 앱 | 알림 접근 |
| 배터리 잔량·온도·전류, 메모리·저장공간 사용량 | 홈, 성능, 주간 리포트 | 없음 |
| 설치된 앱 목록과 권한 허용 상태 | 앱 권한 점검 | 없음 |

## 2. 휴대폰 안에 저장하는 정보

- 주간 리포트용 기록(정리한 용량, 온도, 관리 점수, 충전 습관): 최근 60일
- 휴지통에 옮긴 파일: 이용자가 정한 보관 기간(3~30일) 후 자동 삭제
- 중복 사진 분석 결과(사진별 요약값): 다시 분석할 때 속도를 높이는 데만 사용

이 정보는 앱을 삭제하면 함께 지워지며, 설정 화면에서도 지울 수 있습니다.

## 3. 인터넷 사용

직접 설치 버전은 새 버전이 있는지 확인하고 내려받을 때만 GitHub(github.com)에 접속합니다. 이때 이용자의 정보는 보내지 않습니다. 플레이 스토어 버전은 인터넷으로 정보를 보내지 않습니다.

## 4. 제3자 제공·광고

앱은 정보를 제3자에게 제공하지 않으며, 광고나 분석 도구를 포함하지 않습니다.

## 5. 파일 삭제에 대해

앱은 이용자가 직접 선택한 파일만 휴지통으로 옮깁니다. 휴지통의 파일은 보관 기간 안에 언제든 원래 자리로 복원할 수 있습니다.
