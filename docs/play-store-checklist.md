# 플레이 스토어 등록 체크리스트

## 이미 준비된 것 ✅
- 정식 서명 키 (업로드 키로 사용) — 백업 필수
- Android 16(API 36) 타깃
- 스토어용 버전: 앱 안 자동 업데이트·앱 설치 권한·배터리 최적화 직접 요청 권한 제거
- 스토어 업로드 파일(.aab): 커밋 메시지에 [store]를 넣으면 Releases에 PhoneCare-store.aab가 함께 올라옴
- 개인정보처리방침: docs/privacy-policy.md
- 스토어 소개 문구: docs/store-listing.md

## 직접 해야 하는 것
1. Play Console 개발자 계정 만들기 (등록비 25달러, 신분 확인)
2. 테스터 12명 모으기 → 비공개 테스트 14일 연속 진행 (2023년 11월 이후 만든 개인 계정)
3. 앱 만들기 → 앱 이름·기본 언어(한국어)·앱/게임(앱)·무료
4. **앱 서명**: "Play 앱 서명"에서 가능하면 **'내 앱 서명 키 사용'**을 선택해서 phonecare-release.jks를 등록하세요.
   그래야 직접 설치한 폰케어와 스토어 폰케어가 같은 서명이 되어, 지우지 않고 스토어 버전으로 넘어갈 수 있어요.
   (구글이 만든 키를 쓰면, 스토어 버전으로 바꿀 때 한 번 삭제 후 설치가 필요해요)
5. 스토어 등록정보: docs/store-listing.md 문구, 아이콘(512×512), 그래픽 이미지(1024×500), 휴대폰 스크린샷 2장 이상
6. 앱 콘텐츠 설문
   - 개인정보처리방침 주소 입력
   - 광고: 없음
   - 데이터 보안: "수집하거나 공유하는 데이터 없음" (모든 처리가 기기 안에서만 이뤄짐)
   - 콘텐츠 등급 설문: 도구 앱, 해당 항목 없음
   - 타깃 연령: 18세 이상 권장
7. **권한 신고서** (가장 중요)
   - 모든 파일 접근(MANAGE_EXTERNAL_STORAGE): "파일 관리" 용도. 설명 예시:
     "앱의 핵심 기능은 기기 저장공간 전체에서 정리할 파일(설치 파일, 중복 사진, 메신저로 받은 파일, 큰 동영상)을 찾아
     사용자가 고른 파일을 휴지통으로 옮기고 복원하는 파일 관리 기능입니다. 미디어 저장소 API나 파일 선택기로는
     설치 파일·문서 등 미디어가 아닌 파일과 여러 폴더를 한 번에 검사할 수 없습니다."
   - 포그라운드 서비스(특수 용도): "사용자가 켠 충전 한도·과열 알림을 위해 배터리 상태를 계속 확인" + 시연 동영상 링크
   - 알림 접근: 앱별 알림 '개수'만 센다는 점을 명시
8. 비공개 테스트 트랙에 PhoneCare-store.aab 업로드 → 테스터 초대 → 14일 후 프로덕션 출시 신청

## 거절될 수 있는 부분과 대비
- 모든 파일 접근 권한이 거절되면: 사진·동영상 정리(미디어 저장소) 위주로 줄인 버전이 필요할 수 있어요.
- 포그라운드 서비스 신고가 거절되면: 충전·과열 알림을 '앱을 켰을 때만' 동작하도록 바꿔야 해요.
